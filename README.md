# Программа шифрования и расшифровки текста по матрице (C# WPF)

Этот проект реализует систему шифрования текста с помощью перестановки символов в матрице. В программе есть возможность зашифровать исходный текст и потом расшифровать его обратно.

## Описание

Программа позволяет пользователю вводить текст, задавать размеры матрицы (число строк и столбцов), и выполнять шифрование текста путём перестановки символов по столбцам. Также реализована функция расшифровки зашифрованного текста.

---

## Используемые компоненты

- C# (.NET Framework)
- WPF (Windows Presentation Foundation)
- MSTest (для модульных тестов)

## Инструкция по запуску

1. Скачайте или склонируйте репозиторий.
2. Откройте проект в Visual Studio.
3. Постройте и запустите решение.
4. В интерфейсе:
    - Введите исходный текст.
    - Укажите размеры матрицы: количество строк и столбцов.
    - Нажмите кнопку **"Зашифровать"** для получения зашифрованного текста.
    - Нажмите **"Расшифровать"**, чтобы восстановить исходный текст.

## Основной функционал
Приложение предоставляет графический интерфейс для работы с **матричным шифром (маршрутной перестановкой)**.

### Основные возможности:
*   **Шифрование данных**: 
    *   Текст записывается в матрицу фиксированного размера $N \times M$ по строкам.
    *   Результирующий шифр формируется путем считывания символов по столбцам.
*   **Дешифрование**: 
    *   Восстановление исходного сообщения путем обратной операции (запись по столбцам $\to$ чтение по строкам).
*   **Автоматическое дополнение (Padding)**: 
    *   Если длина текста меньше размера матрицы ($Rows \times Cols$), программа автоматически заполняет пустые ячейки пробелами для сохранения структуры.
*   **Валидация ввода**:
    *   Проверка корректности числовых значений для параметров матрицы (строки/столбцы).
    *   Контроль соответствия длины текста и вместимости выбранной матрицы.
*   **Интерфейс на WPF**: 
    *   Раздельные поля для ввода исходных данных и вывода зашифрованного результата.
    *   Обработка исключений с выводом понятных пользователю уведомлений (`MessageBox`).

### Пример работы:
1.  **Вход**: `ПРИЕЗЖАЮ ЗАВТРА`, Матрица `4x4`.
2.  **Процесс**: Текст дополняется пробелом до 16 символов и записывается в таблицу.
3.  **Выход**: `ПЗ ТРЖЗРИАААЕЮВ ` (результат чтения вертикальных столбцов).
